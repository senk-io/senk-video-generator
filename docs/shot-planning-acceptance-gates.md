# 专业镜头规划与诊断：冻结验收门

本文件写入已经冻结的项目存续验收，并记录本仓库当前观察差距。它不是制度冻结本身，也不把本刀的无模型回归写成规划门或诊断门过线。

草案合同、历史试验与非权威边界仍以
[`one-sentence-shot-planning.md`](./one-sentence-shot-planning.md) 为准。
本文件只回答：三门标准是什么、现在差在哪里、何时可以继续、何时必须停项目。

```text
状态：DRAFT_NON_AUTHORITATIVE
正式 ShotSpec：未创建
质量通过：未创建
本刀真实本地模型套件：未执行
```

## 冻结验收（原文级，禁止软化）

项目存续：规划门 + 诊断门 + 对抗门，三门全过。任一不过 → 停项目。不许降阈值、缩文本、缩写顶覆盖、缺证据补叙事。

规划门（真实本地模型；哭/笑/自行车各 3 轮×7 阶段=63 次）：

- 严格解析 9/9，结构可观察草案 9/9（现状 0/9）
- 锁定字段改写 0；系统编译失败 0
- 同合同三轮：结构一致 1.0，受控语义一致 1.0
- 残余字段不得留「待猜」；留空或自由发挥即失败
- 另加 2 个从未进训练观察的新一句话用例，同样 3/3 结构可观察
- 仍标 DRAFT_NON_AUTHORITATIVE；禁止自称正式 ShotSpec / 质量通过

诊断门：

- 每轮机器可读：覆盖、残余、阻断、不能批准原因；缺一项失败
- 人工盲评 ≥18 轮（9 套件+9 对抗）诊断对错一致率 18/18
- 假通过、漏拦、把一致率写成可接受，任一即整门失败

对抗门（进模型前必须拦死）：

- 固定对抗集 ≥20 条：否定无正向替代、主客机位穿越、固定相机复合冲突、缩写覆盖、锁定字段污染、跨阶段自相矛盾
- 拦截率 20/20；漏 1 条整门失败

砍掉：出片、计费远端、只交合同不跑套件、换小样本冒充过线。

## 过线与停项目判定

### 项目存续成立

只有同时满足以下全部条件，才允许宣称项目在本切片上可以继续，而不是停项目：

1. 规划门全部条目已有真实本地模型、固定修订、零自动重试的 63 次调用证据，并且观察满足上节原文。
2. 两个从未进入既有训练观察的新一句话用例，同样完成真实本地模型 3/3 结构可观察，且不把占位 JSON 计入过线。
3. 诊断门每轮机器可读报告都含覆盖、残余、阻断、不能批准原因；人工盲评 ≥18 轮一致率 18/18。
4. 对抗门固定集拦截率 20/20，且拦截发生在进模型前。
5. 全部产物仍标 `DRAFT_NON_AUTHORITATIVE`；没有自称正式 `ShotSpec` 或质量通过。
6. 没有降阈值、缩文本、缩写顶覆盖、缺证据补叙事、换小样本冒充过线。

任一条件不成立 → 停项目。不得用本刀无模型测试、合同文本或历史一致率替代三门全过。

### 本刀允许完成的范围

本刀只把冻结标准写进仓库，并实现对抗门固定集的无模型拦截与诊断报告骨架。本刀完成不等于项目存续成立。

| 门 | 本刀可交付 | 本刀不得宣称 |
| --- | --- | --- |
| 规划门 | 写明冻结标准与现状 0/9；可放 2 个 held-out 请求占位 | 严格解析 9/9、结构可观察 9/9、一致率 1.0、held-out 3/3 |
| 诊断门 | 对抗阻断路径产出覆盖/残余/阻断/不能批准原因；缺字段失败关闭 | 人工盲评 18/18；整门通过 |
| 对抗门 | 固定集 ≥20 条、六类齐全、无模型权重 20/20 拦截 | 用缩集、降观察阈值或事后叙事补漏拦 |

## 现状差距

权威观察来自 [`one-sentence-shot-planning.md`](./one-sentence-shot-planning.md) 已落盘的套件记录，不是本刀新跑的模型结果。

### 规划门

| 冻结要求 | 当前观察 | 差距 |
| --- | --- | --- |
| 严格解析 9/9 | 第十一版套件 9/9 | 解析稳定不是结构可观察草案 |
| 结构可观察草案 9/9 | 第十一版 0/9；第十二版未执行 | 冻结点写明现状 0/9，本刀仍是 0/9 |
| 锁定字段改写 0 | 第十一版模型未写入锁定字段 | 残余连续性/构图/灯光仍阻断，没有可比较草案 |
| 系统编译失败 0 | 第十一版合并后被连续性或可观察文本阻断 | 编译失败未归零 |
| 结构一致 1.0 且受控语义一致 1.0 | 错误选择上的三轮指纹相同不得写成可接受 | 没有 9 份可比较草案，不能计算过线一致率 |
| 残余不得留「待猜」 | 未形成可发布残余验收 | 留空或自由发挥仍必须失败关闭 |
| 2 个 held-out 新一句话 3/3 | 本刀只允许占位 JSON | 占位不计入过线；未跑真实套件 |
| 仍标草案、禁止正式 ShotSpec / 质量通过 | 现有试验保持 `DRAFT_NON_AUTHORITATIVE` | 必须继续保持；不得借本刀改口 |

第十二版只绑定 `extractor.v2` / `extraction.v2` / `guarded prompt.v12`，没有真实模型套件证据。不得把接线无回归写成规划门过线。

### 诊断门

| 冻结要求 | 当前观察 | 差距 |
| --- | --- | --- |
| 每轮机器可读覆盖、残余、阻断、不能批准原因 | 本刀对抗阻断路径必须产出该四字段 | 规划套件 63 次真实轮次尚未按此结构重跑 |
| 缺一项失败 | 校验器对缺字段失败关闭 | 不得补叙事或事后填空 |
| 人工盲评 ≥18 轮 18/18 | 未执行 | 整门未过 |
| 假通过、漏拦、把一致率写成可接受即整门失败 | 历史文本已禁止把错误选择的一致率写成稳定 | 本刀不得输出通过标签 |

诊断报告不是正式 `Diagnosis` 事实，也不是 `PASS` / `FAIL` 裁决。它只提供机器可读观察骨架；后续权威才能决定接受、失败或人工评审。

### 对抗门

| 冻结要求 | 当前观察 | 差距 |
| --- | --- | --- |
| 固定集 ≥20 条，覆盖六类 | 见 `experiments/shot_planning/adversarial_pre_model_guard_set_v1.json` | 集合本身不是过线；必须 20/20 拦截 |
| 进模型前拦死 | 复用第十二版 `extractor.v2`，不足则追加确定性守卫，不改观察阈值 | 不得把模型调用后的拒绝算作本门拦截 |
| 拦截率 20/20 | 由无模型 unittest 观察 | 漏 1 条整门失败；本刀若测试绿，只证明该固定集的无模型拦截，不证明规划门或诊断门 |

第一版提取器合同保持封闭，供第十一版历史证据重算。对抗门走第十二版提取器与新的进模型前守卫，不覆盖 `trial.v11` 证据。

## 实现边界

```text
CreativeIntent
  -> 一句话请求
  -> v12 原句事实提取
  -> 进模型前确定性守卫
  -> 诊断报告骨架（覆盖 / 残余 / 阻断 / 不能批准原因）
  -> 仅当未阻断时才允许构建第十二版提示
  -> 本地模型残余（本刀不跑）
```

- 模型只出候选；仓库管合同、护栏、证据和状态。
- 失败关闭：未知、缺字段、对抗命中、锁定污染或跨阶段矛盾时，不得进入模型，也不得批准。
- 不伪造质量、选择或时间线事实。
- 本刀不下载、不加载、不推理 Qwen 或其他模型权重。
- 本刀不出片，不计费远端 `execute`。

## 固定对抗类别

机器字段使用稳定英文代码；中文名称与冻结原文对齐，不得用近义改写顶替。

| 代码 | 冻结类别 | 进模型前要拦住的原句形态 |
| --- | --- | --- |
| `NEGATION_WITHOUT_REPLACEMENT` | 否定无正向替代 | 明确否定受控事实，且没有同字段正向替代 |
| `SUBJECT_CAMERA_CROSSOVER` | 主客机位穿越 | 主体附近的相机/镜头/机位承担横向运动，主客方向缠在一起 |
| `STATIC_CAMERA_COMPOUND_CONFLICT` | 固定相机复合冲突 | 「固定相机」或「保持静止」与摇摄、推进或相机横向移动同句并存 |
| `ABBREVIATION_OVERRIDE` | 缩写覆盖 | 用 CU/MS/WS 等缩写或「简称/缩写覆盖」顶替锁定或显式明确词 |
| `LOCKED_FIELD_POLLUTION` | 锁定字段污染 | 要求改写、覆盖或污染已经锁定的系统字段 |
| `CROSS_STAGE_CONTRADICTION` | 跨阶段自相矛盾 | 同一原句在景别、表演、时空或相机策略上跨阶段互斥 |

## 下一刀仍缺的真实套件

下一刀必须在本机真实本地模型上补齐，且不得降阈值：

1. 哭/笑/自行车各 3 轮 × 7 阶段 = 63 次，固定模型修订，自动重试为 0。
2. 观察严格解析 9/9 与结构可观察草案 9/9；锁定字段改写 0；系统编译失败 0。
3. 同合同三轮结构一致 1.0、受控语义一致 1.0；残余不得留「待猜」。
4. 两个 held-out 新一句话同样 3/3 结构可观察，不能用本刀占位 JSON 充数。
5. 规划套件与对抗各至少 9 轮进入人工盲评，诊断对错一致率 18/18。
6. 证据可复核，且仍禁止自称正式 ShotSpec 或质量通过。
