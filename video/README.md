# 视频领域知识

本目录把视频创作经验拆成可引用的领域规则：

- `IntentRules.md`：创作意图如何表达与拆解。
- `ShotRules.md`：镜头实体、用途、时长和连续性。
- `CharacterRules.md`：角色身份与外观一致性。
- `SceneRules.md`：空间、时间、天气和场景连续性。
- `EmotionRules.md`：情绪如何映射为观察项。
- `LightingRules.md`：光照结构、方向、色温和曝光。
- `CameraRules.md`：景别、机位、镜头运动和方向。
- `AudioRules.md`：旁白、音乐、音效和响度关系。

这些文件不能宣布素材已被正式采用。验收和裁决仍由根目录制度及具体项目证据决定。
