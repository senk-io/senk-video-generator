# 镜头规则

- 每个镜头必须有稳定 `shot_id`、对应脚本段、唯一主要用途和目标时长。
- 镜头规格定义“需要什么”，不能包含“已经通过”的结论。
- 镜头应声明景别、主体、动作、构图、相机、情绪、光照和连续性约束中的适用项。
- 一个镜头可以对应多个生成任务和候选资产，但同一正式时间线绑定必须引用获授权的选择决策。
- 上下镜头共享角色、方向、空间或色调时，必须显式声明连续性契约。
- 不满足单一表达意图的复杂镜头应继续拆分。

推荐状态：

```text
DRAFT -> PLANNED -> GENERATING -> CANDIDATES_READY -> UNDER_REVIEW -> SELECTED -> ASSEMBLED -> VERIFIED
```
