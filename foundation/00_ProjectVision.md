# 项目愿景

## 项目定义

本项目是一套受治理的视频生成与剪辑编译系统。

它不把“一次生成一个好视频”作为工程目标，而把以下能力作为长期目标：

> 持续缩小创作预期与实际结果之间的可解释偏差。

## 要解决的问题

普通生成流程通常是一次性的黑箱：提示词进入模型，结果凭感觉被采用，修改原因、素材来源和选择依据随过程丢失。

本项目要建立一条有真源、有状态、有证据、有失败边界的生产链：

```text
Creative Intent
  -> Narrative Contract
  -> Script
  -> Shot Plan
  -> Generation Tasks
  -> Candidate Assets
  -> Selection Decisions
  -> Timeline Assembly
  -> Quality Review
  -> Deliverable
  -> Publication Record
```

## 产品边界

项目拥有的是创作契约、镜头规格、状态迁移、资产来源、裁决记录、依赖传播、质量门和审计证据。

Seedance、Veo、Kling、图像模型、语音模型、FFmpeg 和剪辑器都是可替换能力提供者或编译目标。

## 非目标

- 不建设单一模型的提示词外壳。
- 不把模型返回成功等同于镜头完成。
- 不追求一个提示词全自动完成全部视频。
- 不尝试用单一自动分数裁决艺术价值。
- 不让最终成片反向伪造未曾发生的审批过程。

## 第一阶段成功标准

- 一个视频能从创作目标追踪到最终导出物。
- 每个正式素材都能解释来源、版本和选择理由。
- 修改上游事实后能识别并失效受影响的下游对象。
- 时间线与导出物可由正式事实重复构建。
- 自动检查与人工创意裁决边界清晰。

视频是这套 AI 原生工程方法的第一个验证领域，而不是治理制度的唯一适用边界。
