# 治理制度

本文件由 [`01_FirstPrinciples.md`](./01_FirstPrinciples.md) 派生。任何治理规则都必须先满足 `IF-0001` 权威模型，尤其是权威先于执行、权威不隐式传播、权威不得自证和历史承诺不可变。

所有正式事实还必须满足 [`05_Evidence.md`](./05_Evidence.md) 的 `IF-0006` 证据模型。数据库、文件、接口成功或主体身份都不能替代证据。

制度创建、修订和冻结必须满足 [`06_Institution.md`](./06_Institution.md) 的 `IF-0007` 制度模型。运行时对象不得直接修改制度，修订提案在冻结前没有制度权威。

## 治理目标

治理对象不是艺术结果本身，而是 AI 是否在授权边界内忠实执行了创作意图，以及每个正式事实如何成立。

## 八类权威事实

| 权威 | 回答的问题 | 不得替代它的对象 |
|---|---|---|
| Creative Brief | 视频为何存在、面向谁、表达什么 | 模型提示词 |
| Narrative | 信息结构和论证顺序是什么 | 具体镜头表现 |
| Script | 正式语言内容是什么 | 字幕、配音副本 |
| Shot | 每个镜头要表达什么 | 某次生成结果 |
| Generation Task | 某次模型调用实际请求了什么 | 镜头状态 |
| Asset | 生成或导入了什么候选素材 | 正式选择结论 |
| Selection Decision | 哪个素材被授权采用、为什么 | 成片中的实际出现 |
| Timeline | 正式素材如何被装配 | 导出文件自身 |

## 强制原则

### 单一事实来源

正式文本、状态和决策只能有一个权威来源。字幕、配音、提示词、界面、缓存和导出文件必须引用权威实体或由其派生。

### 单向语义流

```text
Brief -> Narrative -> Script -> Shot -> Asset -> Selection -> Timeline -> Export
```

不得根据“导出效果看起来正确”反推上游脚本、镜头或选择曾合法通过。

### 失败关闭

未知、证据缺失、权威冲突或连续性条件不完整时，停止有风险的状态迁移。AI 不得自行补齐关键事实。

### 生成与裁决分离

生成者生产候选项，评审者或获授权的人决定是否采用。生成 Agent 默认不拥有自己结果的最终采纳权。

### 显式状态

每个正式实体必须具有明确状态。失败、等待人工、被替换、已失效等情况也必须成为正式状态，不能只存在于聊天说明中。

### 证据优先

每次通过、拒绝、选择、替换、失效和发布都必须保留对象版本、判断者、规则、原因、证据位置和时间。

### 变化可解释

任何上游变更必须记录原因、影响范围和失效对象。旧产物不得在依赖已变化后静默保持有效。

### 历史不可伪造

通过追加修订、事件和新决策修复错误。不得删除失败记录或覆盖旧事实来制造虚假的完整过程。

## 冲突处理

事实冲突时先定位各自权威来源。没有明确权威或证据不足时状态为 `UNKNOWN`，并阻断正式选择、装配或发布，直到冲突得到裁决。
